This is a project to make a functional blackjack simulator for the sake of the glorious UConn Blackjack Team. 

ABOUT:
The UConn Blackjack Team is an organization dedicated to improving statistics based decsion-making. We veiw the game of Blackjack as a pathway to understanding probability at a deep level. This project was developed as a tool to help aspiring blackjack players practice their skills, and improve their intuition. If you want to learn basic blackjack strategy and card counting, this is the app for you. If you want to have fun playing blackjack, this is still the app for you.

INSTALLATION:
     Windows:
          Simply Download the .exe file from this page that corresponds to the version you wish to use (The most recent version is always recommended). Find the file in your Downloads folder and then run it. You may need to trust the file first.

     MacOs:
          To run the app on MacOS, first download all of the .py files into the same folder. After doing so, open the terminal and navigate to the folder where you downloaded them. Run the following command:
          python3 main.py

     Linux:
          If you are running Linux, I trust you to figure out how to run a .exe file with Wine. I've personally ran this app on ubuntu 24.04 with no issues. Sorry, but I don't feel like writing a guide for this one.

USAGE:
Use this app to get better at Blackjack! Standard mode allows you to play Blackjack hands for as long as you keep your stack intact, while Drill mode offers a no-stakes environment to practice your weak points with basic strategy. NOTE: All values in this game are NON-MONETARY, this app is free to download and free to play
